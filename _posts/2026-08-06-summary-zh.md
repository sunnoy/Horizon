### [Deno 发布 Celld：自托管、分布式的 Durable Objects](https://github.com/denoland/celld) ⭐️ 8.0/10

Deno 团队发布了 Celld，一个开源的自托管 Durable Objects 实现，基于 SQLite 和 S3 兼容存储进行复制。该项目允许开发者在不依赖 Cloudflare 的情况下运行有状态的分布式无服务器应用，每个持久对象都拥有独立的 SQLite 数据库，并通过名称寻址，数据自动复制到用户拥有的 S3 存储桶中。Celld 旨在提供可移植的、无供应商锁定的有状态服务抽象，简化了分布式系统的构建。

hackernews · calvinfo · 8月5日 16:50 · [社区讨论](https://news.ycombinator.com/item?id=49185430)

**「背景知识」** Cloudflare 的 Durable Objects 是一种有状态服务器计算抽象，每个对象都是可寻址的单写者 actor，拥有一个私有的 SQLite 数据库。Celld 是 Deno 团队开源的自托管实现，它允许在自有机器上运行 Durable Objects，每个对象通过用户拥有的 S3 兼容存储桶进行复制，节点之间仅通过该存储桶协调，无需独立控制平面或共识层。

**「对开发者的影响」** 开发者现在可以自行托管 Durable Objects，使用自己的 S3 兼容存储和 SQLite，无需修改现有 Worker 和 Durable Object 代码，从而避免 Cloudflare 供应商锁定。

**「社区讨论」** 社区对 Celld 的发布普遍持积极态度，认为自托管 Durable Objects 填补了重要空白，但其实际应用场景和与 Cloudflare workerd 的差异尚待明确。也有评论关注到项目因 AI 生成补丁泛滥而关闭 Pull Request 的策略，并对该做法是否会成为趋势提出疑问。

### [往返一致性：双向扩散模型可预测自身展开误差](https://www.reddit.com/r/MachineLearning/comments/1vh2gn1/roundtrip_consistency_bidirectional_diffusion/) ⭐️ 8.0/10

本文提出一种利用双向扩散模型自身往返一致性来估计展开误差的方法。模型在训练时引入方向标志位，使其能按正向或反向时间步进；部署时，先正向展开再反向展开，往返偏差即成为无监督的误差信号，无需真值、集成模型或控制方程。该单一网络在双向动态上的联合训练表现优于两个独立专家模型，并在视频生成与湍流等离子体场等数字孪生任务上得到验证。相关代码与项目页面已公开。

reddit · r/MachineLearning · /u/Clean-Hovercraft5825 · 8月6日 12:10

**「背景」** 在视频预测、时间序列预测等自回归生成任务中，模型逐步预测未来帧，误差会随着长序列的滚动累计而放大，导致长期预测不可靠。然而，部署时没有真实数据可用来衡量误差，因此无需真实数据就能估计误差的方法非常实用。往返一致性（round-trip consistency）利用单个双向模型，它既能向前也能向后模拟时间演化，模型通过比较前进再后退的轨迹与起点的差异，即可自我评估预测误差。

**「影响」** 该方法为视频生成和数字孪生等依赖自回归扩散模型的长序列预测任务，提供了一种无需真值即可检测累积误差的实用手段，有助于提升模型在部署时的可靠性。

### [苹果专用代理泄露用户 IP](https://www.404media.co/apples-private-relay-is-exposing-users-real-ip-addresses/) ⭐️ 8.0/10

安全研究员 Tommy Mysk 与 Talal Haj Bakry 发现，苹果 iCloud+ 的“专用代理”功能存在缺陷，当网站使用 passkey 身份验证时，会泄露用户的真实 IP 地址。该漏洞源于 iOS 上所有浏览器必须使用的 WebKit 引擎：passkey 验证请求由系统凭证服务直接发起，绕过了专用代理的隐私保护路径。任何支持或假装支持 passkey 的网站都可能借此获取用户 IP，且不少网站已无意中收集了这些信息。404 Media 通过研究人员搭建的检测网站实测确认了该问题，苹果回应称正在调查。此前，苹果的“隐藏邮件地址”功能也被曝出类似隐私泄露。

telegram · zaihuapd · 8月6日 03:04

**「背景」** iCloud 专用代理是苹果 iCloud+ 订阅提供的隐私服务，旨在通过两个独立中继服务器隐藏用户 IP 地址和网络请求，防止追踪。passkey 是一种基于公钥的无密码认证标准，通常由操作系统内置的凭证服务处理，而非浏览器本身。由于 iOS 浏览器强制使用 WebKit，而 passkey 验证请求会绕过浏览器网络栈，直接由系统服务发出，导致专用代理的代理路径失效。

**「影响」** 所有依赖 iCloud 专用代理保护隐私的 iOS 用户，在访问支持或冒充支持 passkey 的网站时，真实 IP 地址可能已被网站记录，严重削弱了该服务的匿名保障。该缺陷还波及 iOS 上的 Tor 浏览器 OnionBrowser，进一步扩大了隐私风险。

### [交易所关闭局域网线路，周边金融机柜租金跳涨](https://mp.weixin.qq.com/s/lH2IAcm1uX33Hw1H_EfPDg) ⭐️ 7.0/10

7 月 31 日晚，沪深北交易所关闭机房内的局域网交易行情线路，改为广域网接入，并要求双向时延不低于 2 毫秒，服务器需迁出交易所机房。紧接着，上海金桥、外高桥等地的标准 4000 瓦金融机柜月租金从年初的约 7000 元涨至近万元，部分黄金地段报价翻倍。

telegram · zaihuapd · 8月5日 14:44

**「背景」** 在“价格优先、时间优先”的撮合原则下，离交易所机房越近，指令到达撮合引擎的速度越快，这对高频交易策略的盈利能力至关重要。此前机构可通过局域网直连交易所行情，延迟极低；改用广域网并设定最低时延限制后，任何低于 2 毫秒的传输优势都被消除，服务器必须从交易所内部机房迁出。

**「影响」** 依赖超低延迟的超高频交易策略成本将显著上升，因为它们必须争抢靠近交易所数据中心但租金暴涨的第三方金融机柜，而金桥周边这类机柜仅数千个，供不应求。不过，多家量化私募表示，多数策略无需极致速度，只需“跟着券商走”即可，受影响面有限。
